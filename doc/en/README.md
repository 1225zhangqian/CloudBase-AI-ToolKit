# doc/en —— 英文文档树

与上一层的 `doc/` 完全同构：中文树里有什么文件，这里就有同名的英文对应。

**这棵树是手工维护的**，不由 `scripts/generate-prompts.mjs` / `generate-tools-doc.mjs` 生成。
生成器只写 `doc/` 下的中文产物，跑生成前不会清理这里。

- 新增或修改中文页时，同路径的英文页要一起改
- 对位检查：`npm run check:doc-en`（文件对位失败会退出码 1，标题数/代码块数/中文残留按警告报）
- 文件名以 `-zh.md` 结尾的是中文专用材料（如上架文案），不需要英文对应
