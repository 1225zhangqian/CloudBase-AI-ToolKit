## Enhance an Existing Project

If you already have your own project, after setting up MCP, just tell your AI:

```
Download CloudBase AI rules in the current project
```

It will download and complete the AI editor rule configuration into your project directory automatically—no manual steps needed.

## What's Included

All templates include:

- ✅ AI IDE rules (for different editors)
- ✅ CloudBase MCP configuration
- ✅ CloudBase best-practice project structure
- ✅ Project documentation
